About this project

Technical overview and modeling methodology for presentation and review.

ML

Model Architecture

The application uses a trained Random Forest Regressor (50 decision trees) built with scikit-learn.
  • Supervised regression workflow
  • Hyperparameters tuned via GridSearchCV
  • Achieved an R² validation score of ~71.6%
  • Outperformed Linear Regression and Decision Trees
DS

Dataset & Features

Trained on 1,303 laptop configurations extracted from European retail listings with target variable in Euros (Price_euros).
  • 31 numerical and one-hot encoded features
  • Engineered features for IPS and Touchscreen
  • Categorical mapping for brand, CPU, GPU, OS, and form factor
  • Mean dataset price: €1,123.69 (range: €174 – €6,099)
EX

Scope & Limitations

The model output is a statistical baseline estimate, not a guaranteed resale quotation.
  • Reflects listed catalog retail prices in Euros (€)
  • Does not factor in physical cosmetic condition or wear
  • Does not include battery degradation or device age
  • Intended for academic demonstration and hardware benchmarking
